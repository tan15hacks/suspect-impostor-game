# Release Gates

The game is not production complete until all of these gates pass:

- Full visible feature audit against the specification
- Content validation with at least 1,500 approved word entries
- Flutter format and analysis
- Unit, widget, integration, database, and Firebase-rules tests
- Successful Flutter Web release build
- Successful Android App Bundle release build
- Firebase production configuration and security-rule deployment
- Test-ad and Play Billing verification
- Privacy, accessibility, and low-end Android performance review

No documentation file overrides these gates.
