# Known Limitations

- GitHub Actions and GitHub Pages must be enabled by the repository owner before automated validation and deployment can run.
- Firebase online rooms cannot connect to production until the owner creates a Firebase project and supplies the generated public platform configuration.
- Google Mobile Ads and Play Billing cannot use production products until the owner creates them in the relevant consoles.
- The current branch contains tested domain definitions for advanced systems, but the merged visible game still exposes the Classic web flow only.
- The full 1,500-entry content database, Drift persistence, Firebase room implementation, monetization, localization, accessibility completion, and Android release target are not yet complete.
