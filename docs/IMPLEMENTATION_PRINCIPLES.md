# Implementation Principles

- Build functional systems, not placeholder screens.
- Keep game rules pure and testable.
- Keep secret role data out of public room state and telemetry.
- Preserve offline play when external services are unavailable.
- Use fair monetization with no gameplay advantages.
- Treat accessibility, localization, privacy, security, and recovery as core product work.
- Reuse the Flutter/Dart codebase across web and Android.
